Live hardware path added

ESP32 USB → Python serial bridge (115200 baud) → Server-Sent Events → live browser plots, gait-event processing and experimental ML. CSV and simulated demo are preserved as separate sources. Live physical link must be verified on the connected laptop.

What FSR measures

A force-sensitive resistor changes electrical resistance under pressure. We display the voltage-derived analog reading from each sensing zone.

What MPU6050 measures

A six-axis inertial measurement unit combines three-axis acceleration and gyroscope signals to describe foot movement.

What the analysis detects

Heuristic rules identify contact intervals, approximate heel-to-toe progression and cycle timing variability.

Live & offline demo workflow

  1. Live USB: Run START_LIVE_MAC.commandClose Arduino Serial Monitor; browser opens automatically; live ESP32 numeric rows update sensor cards.
  2. Calibrate idle baseline, then walkRemove pressure for a few seconds, press calibration, then observe actual contact events and estimated gait metrics.
  3. Load steady demoShow regular foot-pressure pulses and consistent gait cycles.
  4. Load irregular demoShow variable cycle timing and pressure transfer; inspect the generated flags.
  5. Import recorded CSVUse your own offline data with columns heel,midfoot,toe,ax,ay,az,gx,gy,gz,time_s.
  6. Save and exportSave analysis results, compare baseline and download CSV files.

Accuracy & limitations

Synthetic-trained Random Forest + rules, NOT a medical device

A real Random Forest is trained only on simulated, algorithmically labelled gait recordings; browser inference runs without a backend. Rule-based event detection remains separate. No participant data or clinically validated real-world accuracy is claimed.

Pressure is not in newtons, cadence requires a same-foot cycle assumption, and one insole cannot independently measure left-right symmetry. The simulated data is labelled as demo throughout the interface.

Live ESP32 USB bridge is included and locally testable. To use actual hardware, close Arduino Serial Monitor and run START_LIVE_MAC.command. Your hardware must output numeric rows continuously. Dataset/classifier accuracy remains unvalidated.
